## 合并时的顺序

1. 收齐上述文件，确认所有截图来自最终实际运行，保留真实来源及限制。
2. 将各人章节合入一个报告，统一图表编号和参考文献，输出根目录 `report.pdf`。
3. 组织 `Visualization Appendix/code/`、`slides/`、`screenshots/`；数据提供方式遵循源许可，保留已验证的重建命令。
4. 在全新目录按README重建并运行，核对主超图、球星、模式和时间的整体验收，确认所有必要文件都在包内。
5. 用实际组号命名 `Group-[组号].zip`，检查大小及解压后运行。未经用户后续指示不上传。
