# C 模块三分钟展示文字提纲

当前优先交付代码。这是后续制作合并 PPT 时可复用的提纲，不是正式 PPT；真实数据与主图接入后再补充比赛案例和截图。

## 第 1 页：从球员进入超图（约 45 秒）

- 研究问题：如何从一名球星进入多人协作/对抗关系？
- 演示：搜索或快捷选择 → 更新统一状态 → B 的主图高亮关联超边。
- 画面：正式主图 + C 详情面板截图。
- 讲解重点：选择的是球员，分析的仍然是三人及以上的关系集合。

## 第 2 页：个人表现与多人组合（约 70 秒）

- 个人：时段指标和全场指标对照。
- 群体：参与超边数、共同参与 Top 5、完整组合频次。
- 演示：点击组合，展开时间与事件证据。
- 可选择成员矩阵展示完整组合的差异；事件展开直接显示传球与接球过程。
- 真实案例：数据接入后填写球员、时间段、次数及来源事件 ID。
- 解释：共同参与频次不等于直接传球次数，也不自动代表配合质量。

## 第 3 页：多视图联动与可信表达（约 55 秒）

- 演示：改变时间段或关系模式，主图与面板同步更新。
- 扩展视角择一简述：同一时间段的双人对比，或射门位置/xG与事件清单；三分钟内避免把全部操作都展开。
- 数据口径：零传球时成功率 N/A；缺失 xG/助攻不补零；排除点球大战。
- 对抗关系是事件窗口推断，需要区分队友与对手。
- 贡献：独立的 C 模块、可复现测试、接口与缺失数据处理。

## 问答准备

- 为什么既有普通比赛指标，又需要超图指标？——分别描述个体事件与多人共同参与。
- Top 5 柱状图是不是普通传球网络？——它是从原始超边导出的辅助统计，主图仍保留完整多人集合。
- 超边为什么在时间边界相交时仍计数？——遵循全组统一规则，保留完整片段，并明确标注。
- 某个指标为何 N/A？——未提供或不足以完整计算，不将未知值冒充零。
