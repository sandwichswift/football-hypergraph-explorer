## 第 1 页：一条跨队超边，需要什么证据？（约 55 秒）

- 核心图示：对抗事件锚点 → 同阶段/连续控球内 ±2.5 秒窗口 → 明确参与者 → 至少三人、至少两队。
- 保留字段：源 `event_ids`、时间、`weight=1`、`event_window_inference`。
- 视觉材料：真实边的证据列表优先；当前可用标记 MOCK 的三事件示意，不能冒充决赛记录。
- 讲解：“我们只收集实际记录的球员与明确传球对象。没有足够证据就不生成边。超边是事件关联推断，不是完整站位或直接一对一对抗。”
- 页下注：5 秒是设计参数；接球对象不等于成功接球。

- 架构链：五份 JSON → 契约/引用校验 → 同一 store → A/B/C/D 独立容器。

## Q&A 预备

- 为什么不是普通图？一条边保留同一个有界片段的三人以上集合，不把它拆成无上下文的两两关系。
- 为什么可能是空数据？证据不足时停止推断；空列表不是没有对抗。
- 计数是不是对抗强度？不是；重叠窗口和记录密度影响数量。
- 如何证实时间联动？独立预期值检查 C 的事件点统计、B 的区间相交和 D 的计数；真实 B 到位后重复全流程。
