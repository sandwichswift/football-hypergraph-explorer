# C 模块正式 PPT 讲稿（约 2 分 45 秒）

正式文件：[part_C.pptx](part_C.pptx)。画幅为 16:9，共 3 页；配色、页眉页脚与 A/B 一致，所有可编辑文字均使用 Microsoft YaHei。PPT 内也已写入对应的演讲备注。

## 第 1 页：从一位球员进入多人关系（约 45 秒）

我们先从 Messi 进入分析。C 可以搜索姓名、球队或球衣号，也可以使用快捷按钮。球员选择写入统一状态，B 主超图随即高亮包含他的超边；反过来，点击主图节点也会更新 C 的面板。左边是实际运行的主图，右边是同一球员的身份与个人指标。入口是一名球员，但分析始终保留三人及以上的完整关系集合。

## 第 2 页：从个人指标走到完整组合（约 65 秒）

全场对抗模式下，Messi 参与 87 条原始对抗窗口，与 Rabiot 共同出现在其中 22 条。窗口可能重叠，这里不能解释成 22 次直接一对一对抗。右边是实际页面中的共同参与 Top 5 和高频完整组合。我们按原始超边计数，并用全部成员集合识别同一个组合。点击组合后，可以查看片段时间和来源事件，同时请求 B 高亮这组完整超边。

## 第 3 页：同一时间窗，切换观察角度（约 55 秒）

改变 D 的时间范围，C 的个人指标、多人关系与 B 主图同步更新。真实案例中，Mbappé 在源时钟 80 到 81 分钟有 1 粒进球，时段值显示 1，下方全场参照仍为 3。C 还支持同时间段的双人对比和射门位置视图；图中的射门可对应到 xG 与事件清单。对缺失字段我们显示 N/A，不把未知当成 0；点球大战也从普通比赛指标中排除。

## 演示顺序与口径

1. 在正式页面选择 Messi，展示 B 主图与 C 面板双向联动。
2. 切换对抗模式，点击一个完整组合，展示证据与 B 的精确高亮。
3. 调整时间范围，展示时段指标和全场对照；剩余时间可打开射门或双人对比视图。
